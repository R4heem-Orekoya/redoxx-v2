## MDX Components

MDX lets you import and use React components directly inside your markdown. This writing demonstrates the pattern — the component below is imported inline.

import Note from "@/components/note"
import YouTubeEmbed from "@/components/youtube-embed"
import { Table, TableHead, TableHeader, TableBody, TableRow, TableCell } from "@/components/table"
import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip"

<Note type="info">

MDX components are imported just like in any React file. This note is a custom component with support for `info`, `warning`, `tip`, and `note` variants.

</Note>

### Tooltip

Hover over the underlined text below to see the tooltip component in action:

<Tooltip>
   <TooltipTrigger className="underline decoration-dotted underline-offset-4 cursor-help text-muted-foreground hover:text-foreground transition-colors">
      MDX
   </TooltipTrigger>
   <TooltipContent side="top" showArrow={false} className="bg-secondary text-foreground">
      Markdown + JSX
   </TooltipContent>
</Tooltip>

<Note type="tip">

Tooltips are great for adding extra context without cluttering the reading flow.

</Note>

<Note type="warning">

Keep interactive components intentional — too many can distract from the reading experience.

</Note>

### Code

Inline code like `remark-frontmatter` and code blocks work as usual:

```json
{
   "remarkPlugins": [
      "remark-frontmatter",
      "remark-mdx-frontmatter"
   ]
}
```

<Note>

Components and markdown mix naturally — you can put a note right beside a code block without breaking the flow.

</Note>
