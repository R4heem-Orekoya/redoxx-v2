Personal website of Raheem Orekoya — a product engineer building software end to end.

Built with Next.js, Tailwind CSS, MDX, and deployed on Vercel.

## Tech stack

- **Framework**: [Next.js](https://nextjs.org) 16 (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com) v4
- **Content**: MDX with `@next/mdx`
- **Syntax highlighting**: Shiki
- **Data fetching**: TanStack React Query
- **Icons**: Hugeicons, React Icons
- **Fonts**: Inter, Geist Mono, JetBrains Mono

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
```
